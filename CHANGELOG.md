# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-06-04
### Added
- Core `envguard` CLI engine with `audit`, `sync`, `diff`, `doctor`, `init`, and `validate` commands.
- Support for JavaScript, Python, Go, Ruby, Rust, PHP, Java, Shell, and Docker environment variable detection.
- Pretty console rendering with Charmbracelet Lipgloss, standard JSON formatting, and GitHub Action annotation output formats.
- Complete test suites covering dotenv parsing, validator rules, and doctor health checks.
- NPM wrapper distribution for global command execution.
- PIP wrapper distribution for Python command integration.
- GitHub Actions CI/CD release integration using GoReleaser.
